CS2 POV Translator v0.9.8 - Read Me First / 先看我

最重要：
不要把新版 zip 直接覆盖解压到旧 cs2pov_arch_project 目录里。
请解压到一个全新的目录，例如：
  D:\agent_workspace\cs2pov_release_tests\cs2pov_arch_project_v0_9_8\

推荐启动方式：
1. 第一次使用：双击 Install_CS2_POV_Translator.bat
2. 安装完成后：双击 START_HERE_DOUBLE_CLICK.bat

v0.9.8 修复：
- Comms Overlay 默认不显示不可靠回合倒计时，只显示 Round + 选手 + 双语通讯流。
- show_at_seconds 仍保留为内部播放时序，方便每回合 overlay 按正确顺序出现。
- 保持 .bat 文件 ASCII-only，继续支持 Anaconda Python 自动发现和一键启动。

正常启动后应看到：
  CS2 POV Translator v0.9.8
  主功能：POV 通讯流 Overlay（按回合校对，再放进剪映）
  6 项核心菜单

如果仍看到 v0.8.x / v0.9.1 / v0.9.2 / v0.9.4 文案：
请关闭窗口，确认你双击的是新解压目录里的 START_HERE_DOUBLE_CLICK.bat。
